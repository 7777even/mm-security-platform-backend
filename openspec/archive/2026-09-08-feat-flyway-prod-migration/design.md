# Design: 生产库在线迁移引入 Flyway

## 依赖与版本

- `spring-boot-starter-flyway`（托管版本 **9.22.3**）。Flyway 9.x 的 `flyway-core` **内置 H2 与 PostgreSQL 社区数据库支持**（v10 才模块化拆分），故 dev(H2) 与 prod(PostgreSQL) 无需额外 DB 模块。
- **达梦 DM8 在 Flyway 社区版无官方 database 模块**：`db/migration/dameng` 仅提供经评审的 DM8(Oracle 兼容) 方言 SQL，运行时能否被 Flyway 探测识别取决于环境是否具备达梦兼容插件（见 `application-dm.yml` 注释）。

## 双轨迁移策略（沿用 AGENTS.md §6.4）

- `V1__init_schema.sql` = **完整快照**（空库直达最新结构），6 张表：
  `sys_user` / `sys_menu` / `fac_device` / `fac_alarm` / `fac_workstation` / `fac_audit_log`。
- `V2__seed_data.sql` = 种子（菜单 5 / 设备 8 / 告警 8 / 工位 3）；`admin` 账号**不进种子**，仍由 `AuthService.ensureAdmin()` 在 Flyway 建好的 `sys_user` 上写入。
- 后续结构变更：新增 `V<yyyyMMddHHmmss>__<snake>.sql` 增量；**已进共享环境的 V 文件禁止改/删/重命名**；三套方言须同步同版本列定义。

## 三库类型映射（列语义一致）

| 语义 | H2 | PostgreSQL | 达梦 DM8 |
|---|---|---|---|
| 自增主键 | `BIGINT AUTO_INCREMENT` | `BIGSERIAL` | `NUMBER(19) GENERATED BY DEFAULT AS IDENTITY` |
| 业务字符串 | `VARCHAR(n)` | `VARCHAR(n)` | `VARCHAR2(n)` |
| 长文本 | `CLOB` / `TEXT` | `TEXT` | `CLOB` |
| 布尔标志 | `BOOLEAN` | `BOOLEAN` | `NUMBER(1)`（0/1） |
| 状态/小整数 | `TINYINT` | `SMALLINT` | `NUMBER(3)` |
| 设备物理主键 | `CHAR(20)` | `CHAR(20)` | `CHAR(20)` |
| 时间 | `TIMESTAMP` | `TIMESTAMP` | `TIMESTAMP` |

- `fac_alarm.alarm_id` 三库均加 `UNIQUE` 约束（幂等种子 + 业务唯一性）。
- 种子幂等：H2 用 `MERGE ... KEY(id)`；PG 用 `INSERT ... ON CONFLICT DO NOTHING`；达梦用 `INSERT ... SELECT ... FROM dual WHERE NOT EXISTS`。

## 配置

- `application.yml`：`spring.flyway.enabled=true`、`spring.flyway.encoding=UTF-8`、`spring.flyway.baseline-on-migrate=true`、`spring.sql.init.enabled=false`；默认 `locations=classpath:db/migration/h2`。
- `application-dev.yml`：移除 `spring.sql.init` 块，Flyway 位置继承 base(h2)。
- `application-prod.yml`：`spring.flyway.locations=classpath:db/migration/postgresql`。
- `application-dm.yml`：`spring.flyway.locations=classpath:db/migration/dameng` + 达梦数据源（驱动 `dm.jdbc.driver.DmDriver`、默认端口 5236）+ 安全基线（签名/JWT 强置、CORS 白名单、关闭 H2 Console 与 SQL 打印）。

## 构建影响

- pom 新增 `dm` profile，内含 `com.dameng:DmJdbcDriver18:8.1.3`（runtime，仅 dm 激活解析），避免无驱动时破坏 dev/默认构建。启用前需 `mvn install:install-file` 本地安装驱动 jar。
- 71 单测（Mockito 独立测试，不启 Spring 上下文）不受 Flyway 影响。

## 验证

- **已实跑（dev/H2）**：`mvn test` 71 绿；`spring-boot:run` 启动日志显示 Flyway 校验 2 迁移并应用 V1+V2 至 `v2`；接口验证种子数据：设备 8 / 告警 8 / 工位 3 / 菜单 5；`AuthService.ensureAdmin()` 在 Flyway 建表后写入 admin；`/actuator/health` 200。
- **评审级（PG / 达梦）**：按标准方言编写，无实例可实跑，须上环境复核。
