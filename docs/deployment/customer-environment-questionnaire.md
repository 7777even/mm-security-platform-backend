# 客户环境问卷（Customer Environment Questionnaire）

> 阶段 7「生产就绪」前置采集清单。**部署/联调前必须与客户/甲方对齐**，结论回填到 `backend-scaffold/docs/requirement/scope-inventory.md` 的「部署约束」列。本文是模板，不随代码演进，按需复制填写。

## 0. 用途与时机

- **何时填**：进入阶段 7（达梦 DM8 实测 / prod 联调 / 部署演练 / 安全渗透复核）前。
- **谁填**：实施方 + 甲方运维/信创负责人联合确认。
- **产出**：一份带勾选与缺省值的问卷，作为 `dameng-migration-runbook.md` 与 `penetration-checklist.md` 的输入。
