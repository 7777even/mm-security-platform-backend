## 3. 安全与合规

| # | 问题 | 推荐默认值 | 备注 |
| - | ---- | ---------- | ---- |
| 3.1 | 等保二级/三级 | ✅ **三级**（石化工控通常三级） | 驱动审计留存与加密强度 |
| 3.2 | 审计留存期 | ✅ **≥180 天**（或按等保三级要求） | 影响 `fac_audit_log` 归档 |
| 3.3 | 密码/密钥管理 | ✅ **环境变量 / `env_file` 注入**（支持 Vault/KMS 后续接入） | `JWT_SECRET`/`SIGNATURE_SECRET` 缺失即 fail-fast |
| 3.4 | CORS 白名单域名 | ⏳ **待甲方**（逗号分隔，**不可含 `*`**） | 空/`*` → 启动即 `IllegalStateException` |
| 3.5 | 防重放签名 | ✅ **是（生产强制 `signature.enabled=true`）** | dev 挂起，prod 必开 |
| 3.6 | 渗透测试窗口与范围 | ⏳ 待甲方（时间/网段/是否含社工） | 决定 release 窗口 |
