# 冻结的原型占位域（红线）

以下域在 ④ 全量推进中被判定为「依赖外部能力 / 待产品确认」，按红线冻结，
不在此次真后端化范围内。待产品确认通信网关与数据来源后，再按 mgmt-ledger
或独立 Controller 接入。

| 域 | 说明 | 冻结原因 |
|----|------|----------|
| comm-sms | 短信通知 | 依赖短信网关对接，待产品确认 |
| comm-call | 语音呼叫 | 依赖呼叫中心对接，待产品确认 |
| comm-broadcast | 应急广播 | 依赖广播系统对接，待产品确认 |
| comm-push | 移动推送 | 依赖消息推送平台，待产品确认 |
| comm-intercom | 可视化对讲 | 依赖音视频对讲平台，待产品确认 |

注：ef-equipment（应急装备）因 V51 未种子化其列结构，亦暂缓，待产品定列结构后补。
